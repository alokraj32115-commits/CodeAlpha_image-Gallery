# 🖼️ Image Gallery

## 📌 Project Overview
The Image Gallery is a responsive web application built using **HTML, CSS, and JavaScript**. It displays a collection of images in an attractive grid layout with interactive features such as a lightbox view, next/previous navigation, hover effects, and smooth transitions. The project is designed to provide an engaging and user-friendly image browsing experience across all devices.

---

## ✨ Features

- 📷 Responsive image gallery layout
- 🔍 Lightbox image preview
- ⬅️ Next and Previous image navigation
- 🎨 Hover effects with smooth animations
- 📱 Mobile-friendly responsive design
- ⚡ Smooth transitions for better user experience
- 🗂️ Image categories/filters (Bonus Feature)

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the gallery
- **CSS3** – Styling, responsive layout, animations, and hover effects
- **JavaScript (ES6)** – Lightbox functionality, navigation, and image filtering

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Double-click **index.html** or open it using any modern web browser.
4. Browse the gallery and use the lightbox navigation.

---

## 📖 How It Works

- Images are displayed in a responsive grid.
- Clicking an image opens it in a lightbox.
- Users can navigate using **Next** and **Previous** buttons.
- Hover effects provide interactive visual feedback.
- Image categories allow users to filter displayed images.
